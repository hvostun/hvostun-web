# Хвостун: Дома Спокойно

## Локальный запуск

```bash
bun install
bun run dev
```

Сайт откроется на http://localhost:5173.

## Доступ снаружи через tuna

Cloudflare / Wrangler не нужны — tuna пробрасывает локальный `dev`-сервер.

CLI ставится отдельно: [установка tuna](https://tuna.am/docs/guides/install/install-cli/). Docker не нужен.

Скопируй пример и заполни `.env`:

```bash
cp .env.example .env
```

Нужны `TUNA_TOKEN` и **один** из вариантов:

- `TUNA_DOMAIN` — свой домен (`tuna http 5173 --domain=…`)
- `TUNA_SUBDOMAIN` — поддомен tuna (`tuna http 5173 --subdomain=…`)

Опционально: `TUNA_LOCATION` (`ru` или `nl`).

В одном терминале подними сайт, в другом — туннель:

```bash
bun run dev
bun run tunnel
```

Пока оба процесса работают, сайт открывается по адресу tuna. Остановил их — адрес перестаёт отвечать.

## Яндекс Метрика

Перед включением проверьте, что опубликованная политика конфиденциальности описывает использование аналитики и что применимые требования к согласию выполнены. В коде Вебвизор не включен, форма и контакты в события не передаются.

1. Сайт настроен на счетчик `114251928`. Чтобы включить его, на машине, с которой работает `hvostun.com`, задайте `VITE_YANDEX_METRIKA_ENABLED=true` в `.env` и перезапустите Vite. Для сборки задайте переменную до `bun run build`. Без флага счетчик не запускается; с флагом он работает только на `hvostun.com` и `www.hvostun.com`.
2. В разделе [«Цели» Яндекс Метрики](https://yandex.ru/support/metrica/ru/general/goal-js-event) создайте три цели типа «Целевое событие», с условием точного совпадения идентификатора:

   | Цель | Идентификатор | Что считается |
   | --- | --- | --- |
   | Помочь исследованию | `research_click` | Клик по кнопке перехода к исследованию |
   | Участвовать в пилоте | `pilot_click` | Клик по кнопке перехода в Telegram, не отправленная заявка |
   | Условное дочитывание статьи | `article_read` | Не менее 30 секунд на видимой вкладке и достижение конца текста, один раз за открытие |

3. Открытия статей смотрите по адресам отдельных материалов `/polezno/...` в [отчете «Популярное»](https://yandex.ru/support/metrica/content/popular.html). В целях есть параметры `placement` для кнопок и `article_slug` для дочитывания.
4. На опубликованном сайте [проверьте загрузку счетчика](https://mobi.yandex.com/support/metrica/ru/general/check-counter) и отдельно каждую цель. Изменение только якоря в адресе не должно создавать просмотр, а быстрый уход со страницы статьи не должен засчитываться как дочитывание.
